框译 v1.0 · 使用说明
================================

1. 启动
   双击桌面上的「框译」快捷方式，或 程序\KuangYi.exe。
   程序\ 是自包含完整版，已内置 .NET 10 运行时和离线模型，解压即可运行，
   不需要另外安装 .NET。
   如果你下载的是「程序本体 + 离线语言包」两个压缩包，请先把两个包都解压，
   再把 离线语言包 里的 models 文件夹放到 KuangYi.exe 同一层目录，
   最终目录里应同时有 KuangYi.exe 和 models\。
   第一次打开会弹出《免责声明》，必须点击“我已知悉”才能关闭并继续使用；
   接受后会记住，以后不再弹出。完整内容见 程序\免责声明.txt。
   启动后会打开一个控制窗口：可以点「框选翻译 (F2)」，也可以直接按 F2。
   主窗口不在任务栏显示图标，只驻留在任务栏右下角的通知区域（托盘，可能在 ^ 里）。
   右上角「—」最小化到托盘；左键点托盘图标可恢复/再最小化。
   「✕」退出程序。最小化后仍可按 F2。
   托盘右键菜单里有「显示主窗口」「显示翻译结果」。
   主窗口和翻译结果窗的位置会被记住，下次启动/下次框选时回到上次的位置。

2. 使用
   按 F2，或点控制窗口里的「框选翻译 (F2)」。
   拖拽框选屏幕区域，松开鼠标开始识别并翻译。
   Esc 取消框选；结果窗可复制译文、重译。
   结果窗也不占任务栏，点「—」最小化到托盘；「✕」隐藏，
   托盘「显示翻译结果」或主窗口「结果」按钮可再打开。
   结果窗右上角「置顶」默认关闭，点一下可固定在其他窗口上层；
   按住结果窗顶部或边缘可自由拖动到任意位置。
   译文会按原文句子自动分段，不再挤成一整块。
   翻译已改为后台快速解码：界面不会再卡住，长段落通常几秒内完成。

3. 离线翻译
   程序\models 已内置 8 个方向、约 1.55 GB 模型。
    如果使用分开下载的「程序本体 + 离线语言包」，models 来自离线语言包，
    解压后必须放在 KuangYi.exe 同一层目录。
   日文/韩文到中文改为多语模型直译，不再经英语中转，准确性更好；
   长文翻译会多花一些时间。
   断网可用；在线翻译默认关闭，可在结果窗一键开启。
   设置 → 识别与数据 可查看已安装方向和识别语言。

4. 设置与数据
   控制窗口里的「设置」按钮，或托盘右键 → 设置。
   数据目录：%LOCALAPPDATA%\KuangYi
   如果系统限制用户目录写入，会自动改写到 程序\KuangYiData。

5. 目录说明
   程序\        自包含完整版（含 .NET 运行时、models、说明文档）
   源码\        源码仓库（KuangYi.sln、README.md、构建/发布脚本）
   产品大纲.md  产品设计大纲
   免责声明.txt  免费、无广告、本地运行与责任说明
   DeepL注册及使用教程.txt  DeepL API 免费 Key 的注册与填写方法
   LibreTranslate自建教程.txt  自己部署免费翻译服务的方法
   离线模型说明.md  模型来源、许可证与质量说明
   GitHub新手上传教程.md  从零上传源码和发布包的步骤

6. 重新构建
   需要 .NET 10 SDK，在 源码\ 下执行：
     dotnet build .\KuangYi.sln -c Debug
   重新发布：
     powershell -ExecutionPolicy Bypass -File .\scripts\publish.ps1

7. 识别语言限制
   Windows 自带 OCR 只包含系统已安装的语言包。
   日文、韩文、俄文需要安装对应的 Windows OCR 语言包：
   设置 → 识别与数据 → 「安装识别语言包」，会打开系统“语言和区域”页面，
   给对应语言安装“光学字符识别”，完成后关闭并重新打开框译。
   安装过程由 Windows 负责；如果 Windows Update 卡住，重启电脑后再试。

8. 已知限制
   英→日为多语模型，质量中等；词典数据包、安装器、签名、自动更新尚未提供。

9. 排查
   · 双击后提示“框译已经在运行”
     说明已有实例驻留。先退出旧实例（控制窗口「退出」或任务管理器结束
     KuangYi.exe），再启动。
   · 启动时提示“快捷键不可用”
     说明 F2 被其他程序占用。打开 设置 → 全局热键，改用 Ctrl+Alt+F2 等组合键；
     也可以直接用控制窗口的「框选翻译」按钮。
   · 日文/韩文识别成乱码
     说明系统没装对应 OCR 语言包，按第 7 节安装后重启框译。
   · 没有看到托盘图标
     不影响使用：控制窗口和 F2 都能工作。若想要托盘图标，点任务栏右下角 ^
     展开，把「框译」拖出来固定。
   · 仍然没有反应
     查看日志尾部：
       Get-Content "$env:LOCALAPPDATA\KuangYi\logs\app.log" -Tail 30
     若用户目录被限制，日志在 程序\KuangYiData\logs\app.log。
     并确认任务管理器里有 KuangYi.exe。
