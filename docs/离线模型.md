# 离线模型说明

## 组成

| 方向 | 来源 | 运行时 | 大小（int8） | 说明 |
| --- | --- | --- | --- | --- |
| en→zh | Xenova/opus-mt-en-zh | ONNX Runtime | ~108 MB | OPUS-MT 直连 |
| zh→en | Xenova/opus-mt-zh-en | ONNX Runtime | ~108 MB | OPUS-MT 直连 |
| en→ru | Xenova/opus-mt-en-ru | ONNX Runtime | ~106 MB | 英语枢轴 |
| ru→en | Xenova/opus-mt-ru-en | ONNX Runtime | ~106 MB | 英语枢轴 |
| en→ja | Xenova/m2m100_418M | ONNX Runtime | ~598 MB | 多语模型；质量中等 |
| ja→en | Xenova/opus-mt-ja-en | ONNX Runtime | ~103 MB | OPUS-MT 直连 |
| en→ko | 基于 Helsinki-NLP/opus-mt-tc-big-en-ko 的 int8 导出（R4kSo1997） | ONNX Runtime | ~267 MB | 附带 source.spm / target.spm |
| ko→en | Xenova/opus-mt-ko-en | ONNX Runtime | ~108 MB | OPUS-MT 直连 |

- 模型以 `encoder_model_quantized.onnx` + `decoder_model_quantized.onnx` + `tokenizer.json`（或 `source.spm`/`target.spm`）+ `config.json` 的形式存放在 `models/<方向>/`。
- 推理为 C# 自实现：SentencePiece Unigram / BPE 分词、Marian 编码器-解码器、CPU 束搜索；M2M100 使用语言标记（`__en__` / `__ja__`）与贪心解码。
- 五语互译共 20 个方向：直连优先，缺直连时经英语枢轴（例如日→中 = 日→英→中）。

## 许可证与署名

- OPUS-MT 模型（Helsinki-NLP）采用 **CC-BY-4.0**，使用时需保留署名。
- M2M100-418M（facebook）采用 **MIT**。
- 模型转换与量化由 Xenova、R4kSo1997 等第三方完成，许可证沿用上游模型。
- 本项目代码不包含模型权重；`models/` 由 `scripts/download-models.ps1` 拉取，分发时请随包附带本说明。

## 质量与性能

- 中英、中俄、中韩直连质量较好；英→日为多语模型折中方案，常见问候语可能选词不准。
- 短句推理约 0.7–3 秒（24 线程 CPU），首次使用需加载模型 1–3 秒。
- 模型闲置 10 分钟后自动卸载；同时活跃的方向数越多，内存占用越高。
- 长文本按 180 字切块顺序翻译，块间不共享上下文。
