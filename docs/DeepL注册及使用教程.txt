DeepL 注册及使用教程
======================

一、先说明
框译的“DeepL 在线”使用的是 DeepL 官方 API，不是网页版 DeepL 翻译器。
需要注册一个 DeepL API 账号并获取 API Key；免费版通常每月约 50 万字符，
具体额度、是否要求付款方式等以 DeepL 官网页面为准。

二、注册 DeepL API 免费账号
1. 打开浏览器，访问：
   https://www.deepl.com/pro-api
2. 在套餐页面选择 “API Free / DeepL API Free”（免费版）。
3. 按页面提示注册账号、验证邮箱。
   如果你已经有普通 DeepL Translator 账号，按官网说明可能需要退出后
   重新创建一个 API 账号，不能直接混用。
4. 如果注册页面要求填写付款方式，通常只是身份验证；
   免费额度内不会收费，请以页面显示为准。

三、获取 API Key
1. 登录后打开：
   https://www.deepl.com/your-account/keys
2. 找到 “Authentication Key for DeepL API / API 密钥”，复制整串 Key。
3. 免费版 Key 通常以 “:fx” 结尾。
   框译会自动识别：
   - 以 :fx 结尾 -> 使用 api-free.deepl.com（免费版）
   - 其他 Key   -> 使用 api.deepl.com（付费版）

四、在框译里使用
1. 打开框译 → 设置；
2. 勾选“启用在线翻译”；
3. “服务”选择 “DeepL（免费版，需要 API Key）”；
4. 把 API Key 粘贴到“DeepL API Key”输入框；
5. 确认“仅本地模式”没有勾选；
6. 点击“保存”。

之后正常按 F2 框选翻译。翻译成功时，结果窗底部会显示：
“DeepL 在线 · 源语言 → 中文”

五、额度与用量
- 免费版一般每月约 50 万字符；超出后 DeepL 会拒绝请求。
- 可在 DeepL 账号页面查看本周期用量：
  https://www.deepl.com/your-account/usage
- 框译在 DeepL 失败时会自动回退到离线模型，不会中断使用。

六、常见问题
1. 结果仍显示“离线模型”
   - 检查“启用在线翻译”是否勾选；
   - 检查“仅本地模式”是否被勾选（勾选后会禁止联网）；
   - 检查 Key 是否复制完整、是否以 :fx 结尾；
   - 检查网络是否能访问 api-free.deepl.com；
   - DeepL 失败（额度、限流、网络）后会自动回退离线模型。

2. 返回 403
   API Key 无效、复制不完整，或使用了错误环境的 Key。

3. 返回 456
   本月免费额度已用完。可以等下个月重置，或改用 MyMemory、
   自建 LibreTranslate、离线模型。

4. 返回 429
   请求过于频繁，稍后再试。

5. 返回 400
   通常是源语言/目标语言代码不被 DeepL 支持，或文本太长。

6. 担心隐私
   启用在线翻译后，识别出的文字会发送给 DeepL。
   如果不想联网，请关闭在线翻译并勾选“仅本地模式”，
   此时框译只使用本机 OCR 和离线模型。

7. API Key 安全
   Key 保存在本机设置文件里，请不要把 settings.json 发给别人；
   如果泄露，请到 DeepL 账号页面重新生成 Key。

七、其他免费方案
- MyMemory：不需要 Key，免费公共接口，有额度和质量限制；
- LibreTranslate：可自己用 Docker 部署，框译里填地址即可；
- 离线模型：完全本地，断网可用，不消耗在线额度。
