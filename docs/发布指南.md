# 发布指南：GitHub 与发给朋友

这份指南说明如何把「框译」发布到 GitHub，以及如何打包发给朋友。

## 一、先分清两种东西

1. **源码仓库**：只放代码、脚本、文档，体积很小（约 1 MB）。
2. **运行包**：`程序\` 目录，约 1.7 GB，包含 8 个离线翻译模型和 .NET 10 运行时；
   当前 `程序\` 是自包含完整版，直接压缩发给朋友即可，不需要安装 .NET。

不要把 `程序\`、`models\`、`bin`、`obj`、个人设置、历史记录提交到 GitHub。
仓库里的 `.gitignore` 已经排除了这些路径。

## 二、发布源码到 GitHub

### 0. 已经准备好的两个发布包

`发布\` 目录里有两个 ZIP：

```text
框译-v1.0.1-程序本体-win-x64.zip
框译-v1.0.1-离线语言包.zip
```

- **程序本体**：自包含 .NET 10 运行时和界面，不含模型，约 100–200 MB；
- **离线语言包**：只有 `models\` 和模型许可说明，约 1.1 GB。

用户需要把两个 ZIP 解压到同一个目录，保证：

```text
KuangYi.exe
models\
```

在同一层。不要只发程序本体，否则离线翻译没有模型。

详细的新手步骤见 [GitHub新手上传教程.md](GitHub新手上传教程.md)。

### 1. 安装 Git

Windows 安装 Git for Windows：

```text
https://git-scm.com/download/win
```

安装后打开 PowerShell，配置一次：

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

### 2. 在 GitHub 新建空仓库

浏览器打开 https://github.com/new

- Repository name：例如 `kuangyi`
- 不要勾选 “Add a README file / .gitignore / license”
- 创建后记下仓库地址，例如：

```text
https://github.com/你的用户名/kuangyi.git
```

### 3. 初始化并推送源码

在 `源码\` 目录执行：

```powershell
cd C:\Users\zlp\Desktop\框译\源码
git init
git add .
git commit -m "Initial commit: KuangYi screen translator"
git branch -M main
git remote add origin https://github.com/你的用户名/kuangyi.git
git push -u origin main
```

第一次推送会要求登录 GitHub；推荐使用 Git Credential Manager 浏览器登录，
不要在代码里写账号密码或 Token。

### 4. 推送前检查

```powershell
git status
```

确认没有：

- `models/`
- `程序/`
- `bin/`、`obj/`
- `%LOCALAPPDATA%\KuangYi\settings.json`（里面有 DeepL Key）
- 任何日志、截图中的个人隐私

`.gitignore` 已排除大部分；仍然建议手动检查一遍。

## 三、模型不要放普通 Git 仓库

GitHub 对普通文件有 100 MB 限制，Git LFS 也不适合 1.5 GB
频繁更新的模型。

推荐做法：

### 方案 A：模型放 GitHub Releases（最简单）

1. 用自包含方式构建运行包（见下一节）；
2. 把 `程序\` 打成 zip（约 1.5–1.7 GB）；
3. 在 GitHub 仓库 → Releases → Draft a new release；
4. 上传 zip 作为 Release asset。

注意 GitHub Release 单个附件上限约 2 GB；如果 zip 接近上限，
可以拆成 `app.zip` + `models.zip` 两个附件，或把模型放到网盘/Hugging Face。

### 方案 B：源码仓库只放下载脚本

仓库里保留 `scripts/download-models.ps1`，用户构建后自行下载模型：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\download-models.ps1
```

模型来自 Hugging Face；国内网络可能无法直接访问，
可以在脚本里改用镜像或让用户自备模型。

### 方案 C：单独发布模型包

在 Release 里放：

- `KuangYi-win-x64.zip`（不含 models，约 100 MB）
- `KuangYi-models.zip`（约 1.5 GB）

用户解压后把 `models` 放到 `KuangYi.exe` 同目录。

## 四、构建给朋友的运行包

### 方式 1：直接发送当前 `程序\`（推荐）

当前 `程序\` 已经是自包含完整版，内置 .NET 10 运行时，朋友不需要安装 .NET：

```powershell
Compress-Archive -Path "C:\Users\zlp\Desktop\框译\程序\*" `
  -DestinationPath "C:\Users\zlp\Desktop\KuangYi-v1.0-win-x64.zip" -Force
```

朋友解压后双击 `KuangYi.exe`。

### 方式 2：自己重新构建框架依赖版 / 自包含版

如果重新用 `publish.ps1` 构建，默认是框架依赖版（朋友需要 .NET 10 Desktop Runtime）。

先确认 `源码\models` 存在；如果没有，先下载模型（约 1.5 GB）：

```powershell
cd C:\Users\zlp\Desktop\框译\源码
powershell -ExecutionPolicy Bypass -File .\scripts\download-models.ps1
```

或者把已下载的 `程序\models` 复制到 `源码\models`。

构建自包含版本：

```powershell
cd C:\Users\zlp\Desktop\框译\源码
powershell -ExecutionPolicy Bypass -File .\scripts\publish.ps1 -SelfContained -Output artifacts\publish\win-x64-selfcontained
```

然后把输出目录和模型一起压缩：

```powershell
Compress-Archive -Path ".\artifacts\publish\win-x64-selfcontained\*" `
  -DestinationPath "C:\Users\zlp\Desktop\KuangYi-win-x64-selfcontained.zip" -Force
```

自包含版本体积会增加约 190 MB，但朋友不需要安装 .NET。
如果 zip 超过 2 GB，请改用 7-Zip 压缩或拆分为应用包 + 模型包。

## 五、发布包必须包含的文件

建议运行包里包含：

```text
KuangYi.exe
KuangYi.dll / KuangYi.Core.dll / *.dll / *.json
models\
免责声明.txt
DeepL注册及使用教程.txt
LibreTranslate自建教程.txt
离线模型说明.md
启动说明.txt
LICENSE.txt
CHANGELOG.md
第三方组件与模型许可.md
```

不要包含：

```text
KuangYi.pdb / KuangYi.Core.pdb   调试符号，发布包可去掉
*.lib                             编译用，运行时不需要
%LOCALAPPDATA%\KuangYi\...        个人设置、历史、DeepL Key
KuangYiData\                      本机回退数据
```

## 六、许可证与署名

本项目代码采用 **MIT** 许可证，见 `LICENSE`；允许别人自由使用、修改、再发布，只需保留版权声明。

注意：**模型和代码是两套许可证**，不能把模型简单当成 MIT：

- OPUS-MT / Helsinki-NLP 模型：CC-BY-4.0，分发时要保留署名和许可证说明；
- M2M100：MIT；
- 第三方 ONNX Runtime、SQLite 等：各自许可证。

发布时请保留 `docs\离线模型.md`，并附上 `THIRD-PARTY-NOTICES.md`。
Windows OCR 语言包属于 Windows 组件，不要打包进你的发布包，
让用户自己在系统设置里安装。

## 七、发给朋友的注意事项

1. 朋友需要 Windows 10/11 x64；
2. 第一次打开必须点“我已知悉”免责声明；
3. 日/韩/俄 OCR 需要系统安装对应语言包；
4. 程序未签名，Windows SmartScreen 可能提示“未知发布者”；
   朋友需要点“更多信息 → 仍要运行”；
5. 不要把带 DeepL Key 的 `settings.json` 一起发出去；
6. 1.5 GB 文件建议用网盘/U盘，不要用微信直接传。

## 八、常见问题

### GitHub 拒绝 push，说文件太大

说明 `models` 或 `bin` 被加入了暂存区。执行：

```powershell
git rm -r --cached models bin obj artifacts
git commit -m "Remove build outputs and models"
```

确认 `.gitignore` 生效后再推送。

### Release 上传 2 GB 失败

拆分成应用包和模型包，或使用网盘/Hugging Face 托管模型。

### 朋友打不开，提示缺少 .NET

使用 `-SelfContained` 重新发布，或让朋友安装
“.NET 10 Desktop Runtime x64”。

### 想自动构建 Release

可以加 GitHub Actions，但模型太大，不建议把模型放进 Actions artifact；
推荐 Actions 只构建不含模型的程序，模型单独上传 Release/网盘。
