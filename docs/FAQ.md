# 常见问题

## 启动后提示缺少 OCR 语言包

打开 Windows 设置 → 时间和语言 → 语言和区域，添加对应语言，并在可选功能中安装「光学字符识别」。也可以在框译设置中点击「安装识别语言包」。

日/韩/俄 OCR 需要对应系统语言包。

## 离线翻译不可用

确认 `KuangYi-models.zip` 已解压到程序目录下的 `bin` 内，最终路径为 `bin\models\...`；也可以在设置 → 识别与模型中点击「下载离线语言包」。

模型文件名固定为 `KuangYi-models.zip`，不随程序版本变化。模型内容未变化时不需要重新下载。

## SmartScreen 提示未知发布者

当前是绿色压缩包，没有代码签名。确认文件来自本仓库 Release 后，可选择「更多信息 → 仍要运行」。

## 在线翻译失败

检查 API Key、网络和额度。框译会自动回退到离线模型。日志位于：

```text
%LOCALAPPDATA%\KuangYi\logs\app.log
```

日志不记录原文，API Key 使用 Windows DPAPI 加密。

## 实时翻译的边框和窗口

实时翻译从主窗口或托盘菜单启动，使用独立框选流程，可以自由选择区域大小。

实时窗口会被排除在屏幕捕获之外，因此即使框选范围覆盖到实时窗口，识别仍会读取下面的内容，不会截到窗口本身。

## 如何清除本地数据

打开设置 → 历史与启动 → 数据管理，可以：

- 清除历史与缓存
- 清除历史、缓存和术语表
- 导出/导入设置
- 备份术语表

设置和 API Key 不会随「清除历史与缓存」删除。

## 支持哪些图片格式

PNG、JPG/JPEG、BMP、GIF、TIF/TIFF、WebP。也可以在支持时直接拖拽图片到主窗口。
